## Status: Opgelost

Dit issue is opgelost. Contactpersoon-data is niet meer publiekelijk toegankelijk.

### Situatie voor de fix
Contactinformatie van gemeenten (e-mail, telefoon) was publiekelijk zichtbaar zonder authenticatie. In de oude Softwarecatalogus konden alleen leveranciers van afgenomen pakketten deze info zien.

### Huidige situatie
RBAC blokkeert correct alle ongeauthenticeerde toegang tot contactpersonen:

**Ongeauthenticeerde API-toegang (OpenRegister direct):**
```
GET /api/objects/voorzieningen/contactpersoon?_limit=3
Response: { "results": [], "total": 0 }  -- RBAC enforced
```

**Ongeauthenticeerde API-toegang (OpenCatalogi publications):**
```
GET /api/publications?_schemas=contactpersoon&_limit=3
Response: retourneert organisatie-records, GEEN contactpersonen
```

**Bypass-poging (`_rbac=false` parameter):**
Server negeert de parameter voor ongeauthenticeerde requests -- retourneert 0 resultaten met `_rbac: true` in metadata.

**Geauthenticeerde vergelijking (admin):**
```
GET /api/objects/voorzieningen/contactpersoon?_limit=3 (met auth)
Response: 3 resultaten met volledige PII: voornaam, achternaam, telefoonnummer, e-mailadres
```

### Bewijs
Hertest uitgevoerd met geautomatiseerde browser-agent op 2026-03-01. Alle 5 toegangspaden getest (direct API, publications, specifiek ID, bypass-poging, extend via organisatie) -- geen van allen lekt contactdata.
