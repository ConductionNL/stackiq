## Status: Opgelost

Het filter "Type koppeling" met de waarden "extern" en "intern" is beschikbaar op de zoekpagina.

### Toelichting

Issue #343 vraagt om het toevoegen van een filter "Type koppeling" op de zoekpagina, met de waarden "extern" en "intern". Dit is een afgeleid gegeven: een koppeling met een buitengemeentelijke voorziening is "extern", alle andere koppelingen zijn "intern".

### Verificatie (1 maart 2026)

De zoekpagina is geverifieerd op de lokale ontwikkelomgeving (localhost:3000/zoeken):

1. **Filter "Type koppeling (2)" beschikbaar** -- Het filter is zichtbaar in het filterpaneel op de zoekpagina met twee waarden: "extern" en "intern".
2. **Volledig filterpaneel** -- Het filterpaneel bevat de volgende filters: Type (4), Samenwerkingstype (14), Geregistreerd door (12), Leverancier (2503), Licentievorm (2), Referentiecomponenten (168), Standaardversies (43), Type koppeling (2), Organisatietype (3), Diensttype (3).
3. **Datamodel-configuratie** -- Het veld `koppelingType` op het koppeling-schema is geconfigureerd met `"facetable": true` en `"title": "Type koppeling"`. De waarden worden automatisch afgeleid via de default template `"{{ buitengemeentelijkVoorziening | ifFilled: extern, intern }}"` met `"defaultBehavior": "always"`.
4. **Enum-waarden** -- De twee mogelijke waarden "extern" en "intern" zijn vastgelegd als enum in het schema.

### Implementatie

Het filter werkt via de `koppelingType` property in het koppeling-schema (`softwarecatalogus_register.json`):

```json
"koppelingType": {
    "type": "string",
    "facetable": true,
    "title": "Type koppeling",
    "visible": false,
    "hideOnForm": true,
    "default": "{{ buitengemeentelijkVoorziening | ifFilled: extern, intern }}",
    "defaultBehavior": "always",
    "enum": ["extern", "intern"]
}
```

Het veld is `visible: false` en `hideOnForm: true` zodat het niet op formulieren wordt getoond, maar `facetable: true` zorgt ervoor dat het als filter beschikbaar is op de zoekpagina. De waarde wordt automatisch berekend op basis van of het veld `buitengemeentelijkVoorziening` gevuld is.
