## Status: Grotendeels opgelost

De ArchiMate/GEMMA API is operationeel en vereenvoudigd. Een bug in de OAS-padgeneratie is opgelost waardoor de API-documentatie nu correcte paden toont.

### Toelichting

Issue #148 bevat uitgebreide verbetervoorstellen voor het ontwerp van de GEMMA/ArchiMate API, waaronder: hernoemen naar "ArchiMate API", ID-vereenvoudiging, model-object properties, ArchiMate-type toevoegen, query-parameters uitbreiden, en eigenschapsdefinities vertalen.

### Verificatie (1 maart 2026)

De ArchiMate/GEMMA API is geverifieerd op de lokale ontwikkelomgeving:

1. **AMEF Register operationeel** -- Het register (ID 4, slug "vng-gemma", titel "AMEF") is beschikbaar en gepubliceerd (`published: 2025-01-01`). Het bevat 6 schema's: element, model, organization, property-definition, relation en view.
2. **OAS-padgeneratie gefixt** -- De OAS-documentatie genereerde incorrecte paden (bijv. `/amef/element` in plaats van `/objects/vng-gemma/element`). Twee bugs opgelost:
   - Ontbrekend `/objects/` prefix in gegenereerde paden
   - Gebruik van `slugify(title)` in plaats van de daadwerkelijke register-slug
   - Nu correct: `/objects/vng-gemma/element`, `/objects/vng-gemma/view`, etc.
3. **Query-parameters** -- De volgende query-parameters werken al correct:
   - `type` -- Filter op ArchiMate-type (bijv. `?type=BusinessFunction`)
   - `identifier` -- Zoek op specifiek element-ID
   - `objectId` -- Zoek op object-UUID
   - `_search` -- Full-text zoeken over alle velden
   - `_limit`, `_page` -- Paginering
4. **Publieke toegang** -- Het register is gepubliceerd, waardoor publieke API-toegang mogelijk is.
5. **Vereenvoudigde structuur** -- De API is vereenvoudigd waarbij het volledige AMEF-object is opgenomen onder de property `xml`.
6. **ReDoc documentatie** -- Via het nieuwe endpoint `/api/registers/4/docs` is interactieve API-documentatie beschikbaar met correcte paden.

### Code-wijzigingen

| Bestand | Wijziging |
|---------|-----------|
| `openregister/lib/Service/OasService.php` | Padgeneratie gefixt op twee locaties: `$basePath` gebruikt nu `$register->getSlug()` (met fallback naar `slugify(title)`) en heeft het `/objects/` prefix. Voorheen werd `slugify($register->getTitle())` gebruikt zonder prefix. |

### Beoordeling

De kern-API-functionaliteit is volledig gerealiseerd inclusief de OAS-padfix. De gedetailleerde verbetervoorstellen uit dit issue vereisen re-refinement nu de API-structuur is vereenvoudigd.
