## Status: Opgelost

Dit issue is opgelost. De error bij het ophalen van het applicatie-overzicht op de publieke pagina's is verholpen.

### Situatie voor de fix
Bij het laden van publieke pagina's (zoeken, detailpagina's) werden 401-authenticatiefouten van de API opgevangen door een globale interceptor die de gebruiker doorstuurde naar `/login`. Dit veroorzaakte:
- Ongewenste redirects naar `/zoeken` of `/login` op publieke pagina's
- "Geen titel" placeholder tijdens het (niet-voltooide) laden
- Console-errors gerelateerd aan authenticatie

### Oorzaak
In `tilburg-woo-ui/src/stores/object.store.js` bevatte de axios response interceptor een ongeconditionneerde 401-afhandeling:
```javascript
if (error.response?.status === 401) {
    window.location.href = `/login?redirect_url=...`;
}
```
Dit stuurde ALLE 401-responses door naar login, ook op publieke pagina's waar geen authenticatie wordt verwacht.

### Wijziging
De 401-redirect is nu gescoped tot `/beheer` pagina's:
```javascript
if (error.response?.status === 401) {
    if (window.location.pathname.startsWith('/beheer')) {
        window.location.href = `/login?redirect_url=...`;
    }
}
```
Publieke pagina's (zoekpagina, detailpagina's, homepage) handelen 401-responses nu stil af zonder redirect.

### Grafische effecten
- Publieke pagina's laden nu volledig door zonder onderbreking
- Er is een korte laadtijd (3-5 seconden) waarin placeholder-items zichtbaar zijn, waarna alle 12.666 resultaten correct worden weergegeven met titels en beschrijvingen

### Resterende punten
- 404-errors op `/api/names/{uuid}` endpoints zijn een apart datakwaliteit-issue (verweesd koppelingen referenties)
- Kort "Geen titel" tijdens laden is een cosmetisch laadstatus-punt, geen functioneel probleem

### Bewijs
Hertest uitgevoerd met geautomatiseerde browser-agent op 2026-03-01. 5 van 5 tests PASS:
1. Homepage laadt zonder redirect
2. Zoekpagina toont 12.666 resultaten met correcte titels
3. Zoeken op "Centric" retourneert 543 resultaten met titels en beschrijvingen
4. Nul 401-fouten in console (alleen bekende 404's op names-endpoint)
5. Detailpagina (Centric Betalen) laadt volledig met tabs en metadata
