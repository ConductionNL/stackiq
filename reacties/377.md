## Status: Opgelost

Dit issue is opgelost. Zie #373 voor de volledige beschrijving. Dit issue is een dubbelaar met #373 — dezelfde fix lost beide issues op.

### Situatie voor de fix
De kolom "Diensten" werd niet getoond in het applicatie-overzicht. Diensten aangemaakt voor applicaties (bijv. Key2GBA-V, PinoApp) verschenen niet in de tabel.

### Wijziging
Drie wijzigingen in de tilburg-woo-ui:
1. `diensten` toegevoegd aan het extend array in `con-beheer-page-config-factory.js`
2. Custom renderer voor diensten-kolom toegevoegd
3. Extend-parameter doorgifte naar API gefixed in `object.store.js` en `con-generic-beheer-page.js`

### Bewijs
De diensten-kolom is nu zichtbaar in het applicatie-overzicht. De API ontvangt `_extend[]=diensten` waardoor de dienstdata wordt meegeleverd in de response.
