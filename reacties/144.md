## Status: Geverifieerd

Dit issue is geverifieerd op 2026-03-01 op de lokale testomgeving.

### Analyse
Dit issue gaat over een overzicht met zoek- en filteropties van alle organisaties die pakketten of diensten aanbieden.

**Alle gevraagde functionaliteit werkt:**
- [x] Zoekfunctionaliteit werkt (12.665 resultaten totaal)
- [x] Organisaties zijn vindbaar via zoeken (Type filter: Organisatie met 3.128 resultaten)
- [x] Beschrijvingen worden getoond bij applicaties en organisaties
- [x] Placeholder is aangepast naar "Zoek op naam of trefwoord"
- [x] Organisatienamen worden getoond (niet meer als UUID's)
- [x] Kaarten zijn bereikbaar via toetsenbordnavigatie (tab)
- [x] Zoekresultaten worden niet meer automatisch gestart tijdens het typen
- [x] Meerdere filters beschikbaar: Type (4), Samenwerkingstype (14), Geregistreerd door (12), Leverancier (2.583), Licentievorm (2), Referentiecomponenten (168), Standaardversies (43), Type koppeling (2), Organisatietype (3), Diensttype (3)
- [x] "Wis alle filters" knop werkt correct -- disabled wanneer geen filters actief, enabled na filterselectie
- [x] Leveranciersnaam bij zoekresultaten van applicaties wordt getoond als "(Aangeboden door ...)"

### Verificatie (2026-03-01)
Getest op http://localhost:3000/zoeken:

1. Zoekpagina laadt met 12.665 resultaten en alle filters zichtbaar
2. Type filter "Organisatie" geselecteerd: resultaten gefilterd naar 3.128 organisaties
3. "Wis alle filters" knop klikken: filters gewist, terug naar 12.665 resultaten
4. Leveranciersnaam getoond op applicatie-kaarten: "(Aangeboden door Bloemendaal-Heemstede)", "(Aangeboden door Rotterdam)", "(Aangeboden door Deurne)" etc.
5. Sortering werkt (Naam A-Z standaard, met opties voor datum en relevantie)
6. Paginering werkt (634 pagina's totaal)
