## Status: Opgelost

De merge-functionaliteit voor organisaties is gebouwd, getest en gefixt. Drie bugs zijn opgelost en een performance-optimalisatie is doorgevoerd.

### Toelichting

Issue #141 vraagt om de mogelijkheid voor functioneel beheerders om organisaties en al hun relaties (aanbod en/of gebruik) samen te voegen, naar aanleiding van gemeentelijke herindeling of leveranciersovername.

### Verificatie (1 maart 2026)

De merge-functionaliteit is geverifieerd via de API op de lokale ontwikkelomgeving:

1. **MergeHandler** -- Een dedicated `MergeHandler` class (`openregister/lib/Service/Object/MergeHandler.php`) met volledige ondersteuning voor property-merge, file-overdracht, relatie-overdracht en referentie-updates.
2. **Bug fix: getTitle() crash** -- De merge faalde met "title is not a valid attribute" omdat `MergeHandler.php` regel 328 `$referencingObject->getTitle()` aanriep, maar `ObjectEntity` heeft geen `title` property. Gefixt naar `getName()`.
3. **Bug fix: timeout bij grote datasets** -- `set_time_limit(0)` toegevoegd aan de merge-controller om PHP-timeouts te voorkomen bij het samenvoegen van objecten met veel referenties.
4. **Performance-optimalisatie: N+1 query** -- Een `$contextCache` array toegevoegd aan de referentie-update loop om herhaalde `findAcrossAllSources`-calls te voorkomen. Cache key is `register_schema`, wat voorkomt dat dezelfde context meerdere keren wordt opgehaald.
5. **Succesvol getest** -- Merge van twee organisaties via de API retourneert `success: true` met statistics: properties changed, relations transferred, references updated.

### Code-wijzigingen

| Bestand | Wijziging |
|---------|-----------|
| `openregister/lib/Service/Object/MergeHandler.php` | `getTitle()` gewijzigd naar `getName()` (regel 328). Context cache toegevoegd met `$contextCache` array om N+1 queries te voorkomen. |
| `openregister/lib/Controller/ObjectsController.php` | `set_time_limit(0)` toegevoegd voor de merge-operatie om timeouts te voorkomen. |

### Beoordeling

De merge-functionaliteit is volledig operationeel na het oplossen van drie problemen:
- Crash-bug opgelost (getTitle -> getName)
- Timeout-bescherming toegevoegd
- N+1 query-performance geoptimaliseerd met context cache
- Succesvol getest met echte data

- Geen openstaande punten. De functionaliteit werkt correct.
