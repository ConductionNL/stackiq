## ADDED Requirements

### Requirement: The dashboard shows counts of organisations, applications, services and contracts

The dashboard SHALL show four counts: organisations, applications, services and contracts.

#### Scenario: An information manager opens the dashboard

- **GIVEN** a catalogue with 12 organisations, 40 applications, 8 services and 5 contracts
- **WHEN** the user opens the dashboard
- **THEN** the tiles read 12 organisations, 40 applications, 8 services and 5 contracts
